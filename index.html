05 / WORKING PRINCIPLES

How I approach difficult AI problems.

01

Start with the problem.

Understand the data, constraints, and objective before choosing the architecture or the model.

02

Measure more than accuracy.

Reliability, generalization, latency, calibration, security and total system economics matter.

03

Build for the real world.

Prefer reproducible experiments, observable systems, robust recovery and explicit verification.

04

Make the thinking transferable.

Document the intuition, mathematics, engineering trade-offs and failure modes so others can learn.
